02C — Race Results

Race results

Import race results (RLT / League export)

Import from a Racing League Tools (RLT) .db or a League-export .db (the schema that mirrors the DB: Teams, races, race_results…). The file is read locally in your browser — only the parsed data is sent to the DB. RLT files: pick the series (RLT can hold any series) and, if there are multiple championships for it, the right one; races are matched to the calendar by circuit (feature → race_results, sprint → race_sprints), replacing existing results for a matched race. League-export files carry their own series/teams/calendar/results and are upserted as-is (safe to re-run).

Post-race penalties

Apply stewards' decisions after a race. Every entry is recorded into the DB (race_penalties) as a marker; use Apply to also change the stored results. Penalties: +seconds (time added to the driver's total, finishing order re-sorted & renumbered), DSQ (dropped to the back, 0 pts, status DSQ), Grid (marks a grid drop earned at this race in race_grid_penalties).

Points schema

Edit the points awarded per finish position (1–48) for any series and session type. Saving recalculates every standing from the stored results.

Fastest lap / Pole bonuses

Bonus points per series for fastest lap and pole position, by session type. F1 2024 = +1 fastest lap (main race only); F2 2024 = +2 fastest lap (sprint + feature) and +2 pole. Saving recalculates standings.
