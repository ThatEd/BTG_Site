# Driver Photos

Drop driver headshots here using the naming convention:

```
firstname_surname.png
firstname_surname.webp
```

For example:

- `charles_leclerc.png`
- `lando_norris.webp`
- `oscar_piastri.png`

All lowercase, first name + underscore + last name. The site auto-detects these
files and shows them in the driver profile hero photo (falling back to `.webp`
→ `.png` → the "?" placeholder if no file matches).
